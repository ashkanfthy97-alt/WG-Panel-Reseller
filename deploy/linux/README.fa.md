# نصب نسخهٔ سورس کامل WG_Panel

راهنمای اصلی و فرمان‌های نصب در [README ریشه](../../README.md) است.

از ریشهٔ همین مخزن روی Ubuntu 24.04 x86_64 با دسترسی root اجرا کنید:

```bash
bash install.sh
```

این حالت سریع، کد راه‌اندازی را در نصب نخست خودکار تولید می‌کند و پس از آماده‌شدن HTTPS فقط روی ترمینال SSH نشان می‌دهد. کد موجود در اجرای دوباره حفظ می‌شود. `bash install-gui.sh` نیز همین مسیر را اجرا می‌کند؛ برای ورودی دستی کد، `bash deploy/linux/install.sh` همچنان فعال است.

برنامهٔ اصلی از `app.py` ریشه اجرا می‌شود؛ هیچ clone یا patch دیگری از WG_Panel هنگام نصب انجام نمی‌شود. فایل تنظیمات پنل `.env` و دادهٔ بومی `instance/` در ریشه قرار دارند. `deploy/linux/runtime/` فقط وضعیت نصب، TLS و پایگاه نمایندگی را نگه می‌دارد.

پس از نصب، `https://SERVER_IP:8767/setup` را با اثرانگشت چاپ‌شدهٔ سرور باز کنید. مدیر مادر را با توکن نصب بسازید. `/resellers` برای مدیریت و افزودن نماینده و `/reseller` برای ورود مستقل نماینده است.

تبدیل نصب قدیمی vendor-layout خودکار نیست. سرویس متعلق به مسیر دیگر باید پیش از هر جابه‌جایی داده بررسی شود. این راهنما هیچ فرمان حذف داده ندارد.
