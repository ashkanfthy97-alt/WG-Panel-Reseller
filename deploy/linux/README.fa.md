# فایل‌های نصب قدیمی WG Portal

مسیر پیش‌فرض این محصول اکنون **منوی لینوکسی بومی WG_Panel** است:

```bash
bash wg.sh
```

فایل‌های این پوشه برای حفظ نصب‌ها و داده‌های قبلی باقی مانده‌اند. `deploy/linux/install.sh` نصب‌کنندهٔ قدیمیِ دارای gateway/setup جداگانه است و نصب پیش‌فرض نیست. `install.sh` و `install-gui.sh` در ریشه، منوی بومی را باز می‌کنند.

افزونهٔ نمایندگی از `portal_reseller_native.py` داخل همان برنامهٔ اصلی ثبت می‌شود؛ فایل‌های `portal_reseller.py`، `reseller_store.py` و `reseller_ui/` دوباره استفاده می‌شوند. دادهٔ جدید در `instance/resellers.sqlite3` است؛ فایل موجود `runtime/resellers.sqlite3` در اولویت حفظ و استفاده قرار می‌گیرد.

سرویس‌های نصب قبلی با تغییر سورس متوقف یا حذف نمی‌شوند. انتقال آن‌ها به نصب بومی به بررسی وضعیت همان VPS نیاز دارد. راهنمای اصلی در README ریشه است.
