About Advanced Security
SavingAdvanced policy changes are not active until you press Save advanced settings or the main Save security settings button. Temporary Allow entries are the exception: they apply immediately.
Geo / ASNDisplay-only enrichment for public attacker IPs. The current backend sends the public IP to ipwho.is and caches the result for 24 hours. Country, ASN and provider information never decide whether an address is blocked.
nftablesAn optional host-firewall second layer for repeat offenders. It uses a dedicated inet wgpanel_security table. Application-level blocking remains fully functional when nftables is unavailable.
If nftables is unavailableThe firewall toggle cannot be newly enabled. The panel shows whether the package is missing or the service lacks firewall permission, and provides a copyable remediation command. It never runs package installation or sudo automatically.
