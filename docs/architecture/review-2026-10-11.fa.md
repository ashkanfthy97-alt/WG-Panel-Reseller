# بازبینی نصب و اتصال به WG_Panel — ۲۰۲۶/۱۰/۱۱

## مبنای اجرایی

هسته عملیاتی نسخه مشخص‌شده Azumi67/WG_Panel است؛ مسیر نصب بومی
Python/venv/systemd و راه‌اندازهای اصلی WireGuard و Telegram استفاده می‌شوند.
ظاهر سفارشی پرتال از طریق دروازه محلی به این هسته وصل است.
این ساختار به معنی تکمیل بک‌اند فروش و نمایندگی نیست.

## اشکال‌های اصلاح‌شده

- مسیر پیش‌فرض static در Flask جلوی دریافت CSS/JS پنل اصلی را می‌گرفت؛
  اکنون /static به هسته ارسال می‌شود.
- هدرهای معرفی‌شده در Connection از درخواست و پاسخ پروکسی حذف می‌شوند.
- منو دارای بخش‌بندی رنگی، راهنمای فارسی/انگلیسی، مراحل نصب،
  ورود مدیر، راه‌انداز WireGuard/NAT، راه‌انداز Telegram، وضعیت و لاگ است.
- پورت‌های نصب در runtime/install.conf ذخیره و هنگام ترمیم و بازکردن منو خوانده می‌شوند.
- پیش‌نیازهای CLI اصلی شامل wget، jq، rsync، unzip و sudo افزوده شدند.
- مالکیت سرویس بر اساس پوشه نصب تشخیص داده می‌شود؛ تغییر عنوان سرویس
  توسط منوی اصلی دیگر باعث تشخیص اشتباه نصب دیگری نمی‌شود.
- پیش از تغییر سرویس‌ها، تداخل مالکیت بررسی می‌شود.
- وضعیت فعال/خودکار ربات هنگام مهاجرت سرویس قدیمی حفظ می‌شود.
- انتظار پاسخ HTTP زمان اتصال و پاسخ محدود دارد.
- واحد Mi در API اصلی به گیگابایت تبدیل می‌شود؛ قبلاً ۱۰۲۴ برابر نمایش داده می‌شد.
- Peer مسدودشده غیرفعال محسوب می‌شود؛ disconnected دیگر آنلاین تشخیص داده نمی‌شود.

## شواهد بررسی

شش بررسی محلی با یک سرور HTTP واقعی: فایل static پنل، تغییرمسیر ورود،
حفظ دو کوکی، بدنه POST و CSRF، query string، حذف هدر Connection و
پاسخ صفحه اصلی/فایل ناموجود. بررسی نحوی Bash نیز انجام شد.
این بررسی‌ها جای نصب روی Ubuntu/systemd، اتصال واقعی WireGuard،
ارسال پیام تلگرام یا بررسی امنیتی جامع را نمی‌گیرند.

## محدودیت‌های باقی‌مانده

- روی VPS کاربر دسترسی اجرایی نداریم؛ سلامت نصب آن سرور هنوز تأیید نشده.
- فروش، دفتر اعتبار، جداسازی نماینده‌ها و پرداخت هنوز بک‌اند تکمیل‌شده ندارند.
- بخش‌های عملیاتی کامل در رابط اصلی WG_Panel هستند؛ همه صفحات هنوز
  به ظاهر سفارشی و فارسی منتقل نشده‌اند.
- منوی پیشرفته اصلی می‌تواند پورت، TLS یا نسخه هسته را تغییر دهد.
  تغییر bind باید با دروازه هماهنگ باشد. به‌روزرسانی هسته خارج از نسخه
  پین‌شده نیاز به بازبینی سازگاری دارد.
- هیچ ادعای «بدون حفره امنیتی» یا بازبینی خط‌به‌خط همه فایل‌های upstream نداریم.
